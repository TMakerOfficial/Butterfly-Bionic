Butterfly Bionic

Firmware & User Manual · By T Maker

แฟลชเฟิร์มแวร์หุ่นยนต์ผีเสื้อ พร้อมคู่มือการควบคุมและการจูนแบบละเอียด

แฟลชเฟิร์มแวร์

เลือกเฟิร์มแวร์ที่ต้องการ แล้วกดปุ่มเพื่อแฟลชผ่านสาย USB ได้เลย

⚠ เบราว์เซอร์นี้ยังแฟลชไม่ได้ — ใช้ Chrome หรือ Edge บนคอมพิวเตอร์

ต้องใช้: เปิดหน้านี้ด้วย Chrome / Edge บนคอมพิวเตอร์ แล้วเสียบบอร์ดผ่าน USB
บนมือถือยังแฟลชไม่ได้ (Web Serial ยังไม่รองรับ) — ให้ใช้คอมพิวเตอร์ในการแฟลช

การประกอบ

สาธิตและอธิบายการติดตั้งปีกเข้ากับลำตัวผีเสื้อ ทีละขั้นตอน

สำคัญ: แฟลชเฟิร์มแวร์และเปิดเครื่องให้เซอร์โวอยู่ ตำแหน่งกลาง ก่อนติดปีกทุกครั้ง ไม่อย่างนั้นปีกซ้าย-ขวาจะไม่สมมาตร และเซอร์โวอาจกระแทกสุดทางตอนกระพือ

คู่มือการใช้งาน

อธิบายปุ่มและฟังก์ชั่นต่าง ๆ — แบ่งเป็น 2 ระบบตามวิธีบังคับ

ค่าจูนในหน้าเว็บ

อธิบายการตั้งค่าต่าง ๆ — ปรับแล้วเกิดอะไรขึ้น พร้อมเทคนิค

เปิดหน้าเว็บ config ยังไง?
• ESP-NOW: ดับเบิลคลิกจอยฝั่งซ้ายที่รีโมท → ผีเสื้อเปิด WiFi ชื่อ Butterfly_xxxx → ใส่ (รหัส 12345678) → เปิด Chrome 192.168.4.1
• ELRS: สับสวิตช์ CH6 (AUX2) เป็น ON (ต้องเปิดรีโมทและเชื่อมต่อติดก่อน) → ผีเสื้อเปิด WiFi ชื่อ Butterfly_xxxx → ใส่ (รหัส 12345678) → เปิด Chrome 192.168.4.1
